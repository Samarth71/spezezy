Spezezy offline version
1. Upload ALL these files together to one website folder: index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png.
   Free options: GitHub Pages, Netlify Drop (drag the folder to app.netlify.com/drop), Cloudflare Pages.
2. The site must be https (those hosts are).
3. Open the link once with internet. After that it works without internet.
4. Install: Android - browser menu > Install app. iPhone - Share > Add to Home Screen.
5. To update the app later: replace index.html and change the version name V in sw.js (spezezy-v2 to spezezy-v3).
